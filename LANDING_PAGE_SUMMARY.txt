HOW TO PUBLISH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALL GUMROAD CLI (if not already installed)
   
   macOS/Linux with Homebrew:
   $ brew install antiwork/cli/gumroad
   
   OR using install script:
   $ curl -fsSL https://gumroad.com/install-cli.sh | bash
   
   Then authenticate:
   $ gumroad auth login

2. PREVIEW THE PAGE (validates before publishing)
   
   $ cd /home/user/astro-compas
   $ gumroad products page preview dieila ./landing.html \
     --json --no-input --non-interactive
   
   ✓ Should show clean .sanitization_report
   ✓ Should NOT warn about missing buy elements

3. PUBLISH THE PAGE
   
   $ gumroad products page publish dieila ./landing.html \
     --json --no-input --non-interactive
   
   ✓ Page is now live!

4. GET YOUR PUBLIC URL
   
   $ gumroad products page url dieila --json \
     --jq '.product.landing_url' --no-input --non-interactive
   
   This returns your custom landing page URL

5. TEST THE BUY FLOW
   
   • Open the returned URL in your browser
   • Click a "Get Started" or pricing button
   • Verify Gumroad checkout modal opens
   • Test the purchase flow
